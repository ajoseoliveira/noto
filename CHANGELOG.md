# Histórico de mudanças do Noto

Aqui ficam as mudanças de cada versão que você pode notar ao usar o Noto, da mais nova para a mais antiga.

Cada versão é um título no formato `## [X.Y.Z] — AAAA-MM-DD`. Uma versão que ainda não foi publicada leva `não publicada` no lugar da data.

## [0.2.0] — 2026-11-27

- O Noto tem uma página para baixar o instalador, em português e em inglês.
- O Noto avisa quando há uma versão nova, com dois botões: **Atualizar agora** e **Depois**. Ele nunca baixa nem instala nada sem você pedir.
- Para saber se há versão nova, o Noto consulta o GitHub. Nada do que você escreve vai junto.
- Há uma licença de uso: você pode baixar e usar o Noto de graça; todos os direitos reservados.
- O README e o guia de instalação são públicos, em português e em inglês.
