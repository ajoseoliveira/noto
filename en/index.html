Requirements

  • 64-bit Windows.
  • Installs only for your user, with no administrator prompt.
  • No account needed.
  • Noto works without internet.
  • The app is in Brazilian Portuguese only.

What Windows will show

When you double-click the installer, a blue window appears. Do this:

  1. Double-click the file Noto-Instalador-0.2.0.exe.
  2. The blue window says Windows protected your PC. This is expected.
  3. Click More info.
  4. Click Run anyway.

That is all. The installation takes a few seconds and asks no more questions.

Why does the warning appear?

Windows shows this warning for every program that does not have a paid company signature. Noto does not have one. The warning does not mean the file is dangerous: it only says that Windows does not know the program yet. To be sure the file is the one that was published, use the checksum below.

If your browser warns you while downloading

While downloading, Chrome or Edge may warn that the file is not commonly downloaded. That is normal for a new program: click the three dots next to the warning, then Keep. If another question appears, click Keep anyway.

Checksum

Want to be sure the file is the one that was published? In PowerShell, in the Downloads folder, run:

Get-FileHash .\Noto-Instalador-0.2.0.exe -Algorithm SHA256

The result must match this checksum (SHA-256):

74f1a980b4dccdb833a70e0d4f0ec02641dac71c0bce03ceb1be66091791be3d

If you already installed Noto

If you installed Noto before, download this version once; from now on Noto tells you when a new version is available.

To update by hand, just download the new installer and double-click it. You do not need to uninstall the old version.
