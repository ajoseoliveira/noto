Requisitos

  • Windows de 64 bits.
  • Instala só para o seu usuário, sem pedir administrador.
  • Não precisa de conta.
  • O Noto funciona sem internet.

O que o Windows vai mostrar

Ao dar dois cliques no instalador, aparece uma janela azul. Faça assim:

  1. Dê dois cliques no arquivo Noto-Instalador-0.2.0.exe.
  2. A janela azul diz O Windows protegeu o computador. Isso é esperado.
  3. Clique em Mais informações.
  4. Clique em Executar assim mesmo.

Pronto. A instalação leva alguns segundos e não faz mais perguntas.

Por que o aviso aparece?

O Windows mostra esse aviso para todo programa que não tem uma assinatura paga de empresa. O Noto não tem essa assinatura. O aviso não quer dizer que o arquivo é perigoso: só diz que o Windows ainda não conhece o programa. Para ter certeza de que o arquivo é o que foi publicado, use a soma de verificação abaixo.

Se o navegador avisar ao baixar

Ao baixar, o Chrome ou o Edge podem avisar que o arquivo não é baixado com frequência. É normal para um programa novo: clique nos três pontinhos ao lado do aviso e em Manter. Se aparecer outra pergunta, clique em Manter assim mesmo.

Soma de verificação

Quer ter certeza de que o arquivo é o que foi publicado? No PowerShell, na pasta Downloads, rode:

Get-FileHash .\Noto-Instalador-0.2.0.exe -Algorithm SHA256

O resultado tem de ser igual a esta soma (SHA-256):

74f1a980b4dccdb833a70e0d4f0ec02641dac71c0bce03ceb1be66091791be3d

Se você já instalou o Noto

Se você instalou o Noto antes, baixe esta versão uma vez; daqui em diante o Noto avisa quando houver versão nova.

Para atualizar à mão, basta baixar o instalador novo e dar dois cliques. Não precisa desinstalar a versão antiga.

Você pode baixar e usar o Noto de graça. Não pode copiar, modificar, revender nem redistribuir o app ou o código.
